# Оформление репозитория

## Готовые материалы

- `cover.svg` — обложка главного README, редактируемый вектор.
- `social-preview.png` — карточка ссылки на репозиторий, 1280 × 640.
- Корневой `README.md` — страница проекта на русском языке.

## Настройки GitHub

**About → Description:**

```text
Личный музыкальный атлас для Windows. Коллекция, плейлисты и плеер в вашем ритме. Electron · React · TypeScript.
```

**Topics:**

```text
music-player desktop-app windows electron react typescript audio music-library
```

**Settings → General → Social preview:** загрузить `social-preview.png`.

В About оставить видимыми Releases. Website пока не заполнять: отдельный сайт проекта не опубликован. Не использовать GitHub Pages как ссылку без развёртывания сайта.

## Визуальный стиль

Графит `#181B1F`, медь `#D9996F`, тёплый белый `#F3F0E9`. Логотип «Этикетка», крупный заголовок и рисунок виниловых дорожек. Обложка имеет собственный фон и одинаково читается в светлой и тёмной теме GitHub.

Главный скриншот взят из проверки интерфейса с выбранным логотипом. На нём демонстрационная коллекция; это подписано в README. После следующего изменения интерфейса заменить скриншот на актуальный.

Ссылка скачивания ведёт на список Releases: она не обещает существование неопубликованной версии и показывает пользователю доступные выпуски. Инструкции разработчика рассчитаны на загрузку вместе с исходниками.
