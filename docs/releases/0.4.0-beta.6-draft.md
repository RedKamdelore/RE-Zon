# Re:Zon 0.4.0-beta.6

## Текст песен

- При начале воспроизведения приложение ищет текст в LRCLIB по названию, исполнителю и длительности записи. Синхронные строки имеют приоритет над обычным текстом.
- Результат кэшируется локально. Вручную сохранённый текст имеет высший приоритет; по кнопке можно повторить поиск.
- Слишком отличающиеся по длительности и метаданным версии не подставляются автоматически. Если синхронного текста нет, остаются обычный текст и ручной импорт LRC.

## Большой плеер

- Открывается из текущего трека, панели сеанса, мини-плеера и всплывающего плеера трея. Работает внутри окна приложения.
- Режимы «Обложка», «Текст», «Очередь». Последний режим запоминается. При возврате восстанавливается предыдущая страница и её прокрутка.
- В режиме текста текущая строка крупная и яркая, соседние приглушены; клик по строке перематывает песню. После ручной прокрутки кнопка «К текущей строке» возобновляет слежение.
- Анимированная обложка и фон учитывают настройку уменьшенного движения Windows.

## Проверка и ограничения

Проверены TypeScript, 502 теста, визуальный предпросмотр трёх режимов, сборка установщика и скачивание с проверкой контрольной суммы через electron-updater. Реальное обновление установленной программы и поиск текста на пользовательских треках ещё не проверены. Автоматический перевод текста в эту сборку не входит.
