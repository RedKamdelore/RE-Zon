# Re:Zon 0.4.0-beta.9

Эта бета посвящена предсказуемому воспроизведению, поиску и сохранности коллекции. Песню можно послушать из поиска, не добавляя остальные результаты в библиотеку.

## Что изменилось

- Результаты поиска запускаются во временной очереди. Кнопка `+` сохраняет только выбранную запись; одинарный клик по строке запускает её. В поиске появился выбор места: вся доступная музыка, своя коллекция или SoundCloud.
- При потере сети плеер останавливается на проблемном треке и показывает ошибку вместо быстрого перелистывания очереди. Появилась кнопка **Стоп** в основном и мини-плеере, большом плеере и трее. Запись о прослушивании создаётся после фактического начала воспроизведения.
- Профиль проверяется перед сохранением. Последний исправный файл хранится как резервная копия; при повреждении основного файла приложение восстанавливает его и сообщает об этом. Если обе копии повреждены, приложение не заменяет их пустой библиотекой.
- Будущий трек в очереди можно запустить нажатием. Карточки источников показывают доступные функции, состояние подключения и время последней успешной синхронизации.
- Плейлисты Spotify сохраняют названия и порядок песен при импорте. Их записи воспроизводятся при наличии соответствующего доступного аудио в коллекции Re:Zon. Spotify сам по себе предоставляет здесь метаданные, а не поток для воспроизведения.
- В меню **Источники текста** можно выбрать найденный синхронный или обычный вариант, видеть его происхождение и позже вернуть автоматический выбор. Выбранный вариант и сдвиг строк сохраняются в профиле.

## Как проверить

1. Найдите песню через SoundCloud и нажмите на неё: она должна играть, а число песен в коллекции не должно измениться. Нажмите `+` у одной записи: сохраниться должна только она.
2. Отключите сеть во время потокового воспроизведения: плеер должен остаться на проблемной песне. После возвращения сети нажмите **Слушать** для повторной попытки.
3. Откройте **Большой плеер → Текст → Источники текста**. Если доступно несколько результатов, выберите один, затем верните автоматический выбор.
4. При подключённом Spotify обновите аккаунт и откройте его плейлисты. Для воспроизведения нужны совпадающие доступные записи из других источников.

## Известные ограничения

- Альбомы и плейлисты VK пока не загружаются как отдельные сервисные подборки. Тексты зависят от внешних каталогов, поэтому синхронный вариант доступен не для каждой песни.
- Обновление поверх установленной beta.8 и работа с реальными аккаунтами требуют проверки на пользовательской машине. Установщик не имеет цифровой подписи издателя.
