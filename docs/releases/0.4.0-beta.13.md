# Re:Zon 0.4.0-beta.13 — загрузка на таймлайне и тексты из VK

Теперь на шкале воспроизведения видно, какая часть песни уже загружена. Громкость можно менять колёсиком, а поиск текста проверяет VK вместе с внешними каталогами.

## Что изменилось

- **Светлая полоса загрузки.** Цветная часть таймлайна показывает прослушанное, светлая — загруженные участки потока или прогресс сохранения на компьютер. Полоса учитывает реальные загруженные интервалы, включая разрывы после перемотки. Готовая офлайн-копия отображается как полностью загруженная. Это работает в нижней панели, мини-плеере и карточке трея.
- **Автосохранение VK при прослушивании.** Исправлен запуск автосохранения для заранее подготовленного следующего трека. Доступные прямые аудиофайлы сохраняются при включённой настройке автосохранения; готовая локальная копия используется при следующих запусках песни. Потоковый буфер и сохранённый файл имеют разные подсказки.
- **Громкость колёсиком.** Наведите курсор на значок или ползунок громкости в нижней панели либо в трее. Вверх — громче, вниз — тише, шаг 5%. Уровень сохраняется, прокрутка страницы в этой области не срабатывает.
- **VK стал источником текста.** Для VK-записей текст запрашивается по ID песни через её аккаунт. Для других песен подключённый VK ищет совпадение по исполнителю, названию и длительности. Поддерживаются синхронные строки, обычный текст и старые записи с `lyrics_id`.
- **Результаты VK в меню источников.** Видно, есть ли синхронный текст, обычный, оба формата или ничего. Найденный вариант можно выбрать вручную. Если аккаунт отключён или VK недоступен, меню сообщает об этом; результаты других источников продолжают использоваться.
- **Приоритет синхронного текста.** Обычный текст из VK не заменяет найденный синхронный. При наличии синхронного текста, связанного с точной VK-записью, используется он.
- **Исправлено меню по Alt.** Нажатие Alt больше не раскрывает служебную строку File / Edit / View / Window.

## Как обновиться

В **Настройки → Обновления** выберите канал **Бета**, проверьте обновление, загрузите его и нажмите **«Установить и перезапустить»**. Для первой установки скачайте **ReZon-Setup-0.4.0-beta.13-x64.exe** из Assets этого выпуска.

Новая установка начинается с пустой коллекции, без демо-записей. При обновлении библиотека, настройки и сохранённая музыка остаются в пользовательском профиле.

## Что проверить

1. Включите автосохранение в настройках загрузок и запустите доступный прямой трек VK. Проверьте светлую полосу, статус сохранения и повторное воспроизведение без интернета.
2. Наведите курсор на громкость и прокрутите колесо в обе стороны — в основном плеере и в трее.
3. На песне из подключённого VK откройте **Текст → Источники текста**. Проверьте результат VK, выбор обычного и синхронного вариантов.
4. Нажмите Alt: служебное меню не должно появляться.

## Проверки и ограничения

Перед публикацией выполняются проверка типов, автоматические тесты и сборка Windows x64. Установщик и файлы обновления проверяются на соответствие версии и контрольных сумм, состав приложения — на отсутствие файлов профиля и демо-записей.

Проверка VK выполнена на тестовых ответах, включая таймкоды, старые тексты, разные аккаунты и ошибки. Получение текстов с реального подключённого аккаунта требует проверки в установленной бете. Наличие синхронного текста зависит от конкретной записи и доступности источника. Сохранение офлайн поддерживает доступные прямые аудиофайлы; потоковый буфер сам по себе не становится офлайн-копией. Цифровая подпись издателя пока не настроена.
