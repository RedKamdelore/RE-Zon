# Re:Zon 0.4.0-beta.5

- Проверка обновлений начинается через 1,5 секунды после запуска, если включена автоматическая проверка. При повторном запуске уже работающего приложения проверка также повторяется.
- Когда новая версия найдена, поверх основного интерфейса появляется заметная плашка с номером версии и кнопкой перехода к обновлению. Её можно отложить на время текущего запуска.
- Установщик при обновлении с аргументом `--updated` принудительно переключается в тихий режим. Приложение также передаёт `/S` через electron-updater. Если текущая установка выполнена для всех пользователей, системный запрос прав администратора может сохраниться.
- Исправлен всплывающий плеер из трея: повторные клики больше не открывают главное окно, а панель показывается после загрузки.

Проверены TypeScript, локальная сборка NSIS и скачивание установщика через electron-updater с проверкой контрольной суммы. Полный цикл обновления установленной beta.4 предстоит проверить на Windows.
