# Re:Zon 0.4.0-beta.2

## Окно и системный трей

- Исправлена ошибка `Object has been destroyed` при открытии приложения из трея.
- Крестик скрывает главное окно в трей, сохраняя воспроизведение. Для полного завершения используйте **Выход** в меню трея.
- Свёрнутое окно восстанавливается; уничтоженное окно создаётся заново. Команды трея не обращаются к закрытому окну.
- Повторный запуск приложения открывает главное окно, а не окно авторизации.
- Левый клик по значку в трее открывает квадратный мини-плеер с обложкой, названием песни, перемоткой и кнопками управления. Двойной клик или пункт «Показать Re:Zon» открывает основное окно.
- Выход и установка обновления завершают приложение, не сворачивая его обратно в трей.

## Синхронный текст

- В панели «Текст песни» строки LRC подсвечиваются по позиции воспроизведения.
- Текст автоматически прокручивается; ручная прокрутка приостанавливает слежение. Нажатие на строку перематывает песню.
- LRC можно вставить в редактор или импортировать из файла. Метка `[offset:500]` сдвигает синхронизацию на полсекунды.
- Обычный текст без меток времени остаётся доступным в прежнем виде.

## Офлайн-копии прямых файлов

- В «Сервисы и импорт» можно добавить доступную прямую HTTPS-ссылку на MP3, FLAC, WAV, OGG, OPUS или M4A и сохранить файл на устройство.
- «Настройки → Загрузки» показывает очередь, прогресс, ошибки, отмену и удаление копии.
- Сохранённый файл воспроизводится из профиля без сети. Если копия отсутствует или её проверка завершается ошибкой, плеер пробует исходную ссылку. Неудачная загрузка не отмечается как сохранённая, а повтор запускается из меню записи.
- Кнопка не предлагается для потоков VK и SoundCloud: их потоковые адреса не считаются разрешённой загрузкой оригинала.

## Данные приложения

- Новый раздел **Настройки → Данные приложения** объясняет, почему профиль сохраняется после переустановки.
- **Сбросить данные приложения…** открывает отдельное подтверждение. По умолчанию выбрана отмена.
- Подтверждённый сброс очищает настройки, плейлисты, избранное, тексты, входы в сервисы и кэш профиля после перезапуска.
- Музыкальные файлы вне папки профиля не удаляются. Аккаунты в самих сервисах остаются.
- В новом деинсталляторе появился отдельный флажок удаления профиля. По умолчанию он выключен.
- При обновлении и тихом удалении профиль сохраняется; флажок очистки не применяется.

## Установка и проверка

Windows x64. Установщик не подписан сертификатом издателя.

В beta.1 выберите **Настройки → Обновления → Бета → Проверить обновления**. После публикации этого выпуска появится версия beta.2. Загрузите её и нажмите **Установить и перезапустить**.

После обновления проверьте сохранность коллекции и аккаунтов. Для проверки отмены откройте сброс и нажмите **Отмена**. Проверять подтверждённый сброс следует на отдельном тестовом профиле либо после резервного копирования `%APPDATA%/rezon` при закрытом приложении.

Новый флажок удаления появится в деинсталляторе после установки beta.2. Ранее установленный деинсталлятор beta.1 не изменяется задним числом.

## Проверки

TypeScript, production-сборка, установщик Windows и 493 теста прошли. Проверены сброс профиля, закрытие в трей, пересоздание окна, открытие квадратного мини-плеера, LRC, выбор сохранённого файла при воспроизведении и офлайн-загрузка тестового аудио с перезапуском без сети. Прямая загрузка отвергает локальный адрес, неполный или неаудиоответ. Тестовый цикл electron-updater обнаружил, загрузил и проверил установщик; неверную контрольную сумму отклонил.

Ручная проверка удаления и перезапуска установленной программы с настоящим профилем пользователя, а также проверка обновления beta.1 → beta.2 ещё не выполнялись.
