# Re:Zon 0.4.0-beta.1

Первая тестовая сборка интерфейса Atlas с обновлениями через GitHub Releases.

## Изменения

- Новый интерфейс: Обзор, Коллекция, Источники и боковой Сеанс прослушивания.
- Логотип «Этикетка» в навигации, значке Windows и установщике.
- Настройки → Обновления: каналы «Основное» и «Бета», ручная проверка, автопроверка при запуске и раз в сутки.
- Загрузка обновлений с прогрессом и отдельная команда «Установить и перезапустить».
- Проверка целостности установщика перед установкой. Автоматическая установка при выходе отключена.
- Переключение канала сохраняется. Переход на более старую версию автоматически не выполняется.

## Установка для тестирования

Запустите `ReZon-Setup-0.4.0-beta.1-x64.exe`. Установщик рассчитан на Windows x64, позволяет выбрать папку и создаёт ярлык. Он не подписан сертификатом издателя; Windows может показать предупреждение об неизвестном издателе.

Данные продолжают храниться в `%APPDATA%/rezon`. Если на компьютере уже есть ценная коллекция ReZon, перед тестированием сохраните копию этой папки при закрытом приложении. Установщик не удаляет пользовательские данные при деинсталляции.

## Проверить в полевых условиях

1. Запуск с ярлыка, доступность новой иконки и настроек.
2. Сохранность плейлистов, любимых записей, локальных папок и подключённых аккаунтов.
3. Проигрывание локальных файлов, пауза, перемотка, громкость и эквалайзер.
4. Очередь и порядок плейлиста; поиск, фильтры, избранное.
5. Мини-плеер, системный трей, мультимедийные клавиши.
6. Настройки → Обновления: смена канала, сохранение выбора после перезапуска, ручная проверка.
7. После публикации более новой беты — загрузка и установка через приложение.

Репозиторий обновлений: https://github.com/RedKamdelore/RE-Zon.
До публикации подходящего релиза в GitHub проверка может сообщать об отсутствии доступного выпуска. Сама сборка не публикует файлы автоматически.
