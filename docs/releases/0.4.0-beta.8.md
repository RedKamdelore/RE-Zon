# Re:Zon 0.4.0-beta.8

## Что нового

- Поиск текста использует четыре каталога: LRCLIB, LrcAPI, LrcMux и SyncLRC. Приложение предпочитает синхронный текст и сверяет название, исполнителя, длительность и временные метки, чтобы уменьшить число неверных совпадений.
- Меню «Источники текста» показывает, откуда взят текущий текст. При открытии меню приложение проверяет все четыре каталога и отдельно показывает результат каждого: есть синхронный текст, обычный текст, оба варианта или подходящий текст не найден. Ошибки сети отображаются отдельно.
- Если каталог отдаёт оба формата, в меню видны образцы каждого. Ручной поиск можно повторить кнопкой «Проверить все источники». При временной ошибке повторного поиска уже найденный синхронный текст сохраняется.
- Для каждого трека можно сдвинуть строки караоке раньше или позже шагом 0,5 секунды. Поправка сохраняется между запусками.
- Исправлена компоновка синхронного текста в большом плеере: строки центрируются по реальной высоте области после изменения размера окна, а меню источников остаётся прокручиваемым в компактном окне.

## Как проверить

Откройте трек и перейдите в **Большой плеер → Текст → Источники текста**. Во время проверки виден статус ожидания; после неё каждый каталог получает свой результат. Для записи, которой нет в каталогах, можно добавить текст вручную или загрузить LRC.

Поиск зависит от внешних каталогов и не гарантирует синхронный текст для каждой песни. Браузерный `player-preview.html` показывает явно помеченный пример статусов; настоящий поиск работает в установленном приложении.
