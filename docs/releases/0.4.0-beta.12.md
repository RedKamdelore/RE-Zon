# Re:Zon 0.4.0-beta.12 — нижний плеер, новый трей и плавные переходы

В этой бете управление музыкой снова всегда находится внизу окна. Плеер в трее получил новую компактную карточку, а переходы между экранами и вкладками больше не складывают несколько анимаций поверх друг друга.

## Что изменилось

- **Нижний плеер вернулся.** Обложка, название и исполнитель остаются видимыми на основных экранах и в большом плеере. Рядом доступны воспроизведение, пауза, стоп, перемотка, избранное, очередь, текст, звук и переход в мини-плеер.
- **Новая карточка в трее.** По левому клику открывается квадратный плеер с обложкой, позицией трека, громкостью и основными кнопками. Из него можно сразу открыть текст песни, очередь или большой плеер. Escape и кнопка закрытия прячут карточку.
- **Удобное отключение звука.** Кнопка громкости выключает звук и возвращает предыдущий уровень при повторном нажатии.
- **Переходы без наложений.** При переключении текста, очереди и звука меняется только нужная панель. Обложка, фон и нижнее управление остаются на месте. Быстрый новый клик прерывает предыдущий эффект; системное уменьшение движения учитывается.
- **Компоновка для разных окон.** Нижняя панель перестраивается при уменьшении ширины, чтобы управление оставалось доступным. Из верхней панели убрано повторное управление воспроизведением.
- **Общий стиль.** Карточка трея использует цвета выбранной темы, мягкие поверхности и единый набор иконок. Пустая очередь не показывает активные кнопки воспроизведения.

## Как обновиться

Выберите канал **Бета** в **Настройки → Обновления**, проверьте новую версию и нажмите **«Установить и перезапустить»** после загрузки. Для первой установки скачайте **ReZon-Setup-0.4.0-beta.12-x64.exe** из Assets этого выпуска.

Библиотека, настройки и сохранённая музыка остаются в пользовательском профиле. Новая установка начинается с пустой коллекции, без демо-записей.

## Что проверить

1. Перейдите из коллекции в настройки и обратно: нижний плеер должен оставаться на месте.
2. Быстро переключите **Текст → Очередь → Звук** в большом плеере: вкладки должны реагировать на последний клик без наложения экранов.
3. Нажмите левой кнопкой на значок в трее. Проверьте стоп, перемотку, громкость, открытие текста и очереди, закрытие по Escape и по клику вне карточки.
4. Уменьшите окно и проверьте, что кнопки и таймлайн остаются доступны.

## Проверки и ограничения

Сборка Windows x64, автоматические тесты и проверка типов выполняются перед публикацией. Установщик проверяется на соответствие версии и контрольных сумм; механизм обновления проверяется загрузкой через локальный источник и отклонением повреждённой контрольной суммы.

Компоновка и действия карточки проверены в браузерном превью. Поведение настоящего трея при разных настройках панели задач и масштаба Windows требует проверки на установленной версии. Цифровая подпись издателя пока не настроена.
