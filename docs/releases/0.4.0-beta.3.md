# Re:Zon 0.4.0-beta.3

## Обновление прямо в приложении

- После загрузки обновления кнопка **Установить и перезапустить** завершает Re:Zon, тихо устанавливает новую версию и запускает плеер снова.
- Открывать скачанный установщик и проходить мастер установки вручную не требуется.
- Внутри механизм по-прежнему использует проверенный NSIS-пакет: он заменяет файлы приложения, сохраняя пользовательский профиль.
- Обновления beta.1 и beta.2 доступны через **Настройки → Обновления → Бета**.

Все изменения beta.2, включая квадратный плеер из трея, синхронный текст и офлайн-копии прямых аудиофайлов, входят в этот выпуск.

## Проверка

493 теста и проверка TypeScript прошли. Установщик Windows собран; локальный тест `electron-updater` скачал его, подтвердил контрольную сумму и отклонил файл с неверной суммой. Тихая установка проверена на уровне вызова механизма обновлений. Полный цикл на установленном приложении с реальным профилем пользователя ещё не проверялся.
