# Re:Zon 0.4.0-beta.4

## Плеер из трея

- Левый клик по значку Re:Zon открывает компактную всплывающую панель рядом с треем. Основное окно остаётся в прежнем размере и продолжает воспроизведение.
- Панель показывает обложку, название, исполнителя, состояние воспроизведения и полосу перемотки. Доступны предыдущий трек, пауза/воспроизведение, следующий трек и переход в основное окно.
- Клик вне панели скрывает её. Панель не появляется отдельным приложением на панели задач.

## Загрузки и место на диске

- Трек с доступной прямой HTTPS-ссылкой автоматически ставится в очередь сохранения после начала воспроизведения. При следующем запуске плеер выбирает локальную копию, если она доступна, и исходную ссылку в остальных случаях.
- Автоматическое сохранение можно выключить в **Настройки → Загрузки**. Лимит офлайн-копий выбирается из 1, 5, 20 ГБ или без ограничения; по умолчанию 5 ГБ. Отдельный файл по-прежнему ограничен 300 МБ.
- Добавлены кнопки для сохранения всех прямых файлов, отмены очереди, повтора ошибочной загрузки, открытия папки копий и обновления расчёта места.
- Полоска показывает доли файлов программы, профиля и проиндексированных локальных песен. Отдельно отображаются размер офлайн-копий и свободное место на диске профиля.
- Локальные файлы из папок не копируются повторно. Потоковые адреса VK и SoundCloud не считаются прямой доступной загрузкой и не помещаются в офлайн-очередь.

## Проверка

497 тестов, проверка TypeScript и производственная сборка прошли. Проверены выбор локальной копии, постановка прямого файла в очередь, лимит кэша, подсчёт файлов и расположение всплывающей панели на экране. Тестовый Electron в среде разработки не открыл окно для визуального осмотра из-за сбоя графического процесса, поэтому внешний вид и клик по трею нужно проверить на установленной версии Windows.
