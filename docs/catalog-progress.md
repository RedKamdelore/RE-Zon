# Единый каталог: состояние реализации

## Реализовано
- Каталог объединяет библиотеку и снимки подключённых аккаунтов без изменения исходных ID и плейлистов.
- Сопоставление по точному нормализованному исполнителю/названию и близкой длительности; версии в названиях сохраняются.
- Главная и поиск используют каталог; записи без потока предлагают поиск аудио.
- Выбор источника и последовательные резервные источники в очереди при ошибке.
- Публичный поиск SoundCloud, пагинация, обложки источника. Проверяется домен URL следующей страницы.
- Обложки из Spotify/VK/SoundCloud; ленивый запасной поиск точного альбома MusicBrainz/Cover Art Archive, кэш URL на диске.
- Подборка по любимому, истории ReZon и лайкам аккаунтов. Рекомендации Last.fm могут отправляться в общий поиск.

## Проверено
- TypeScript, production build, 429 тестов.
- Изолированное окно Electron: 3 источника стали 2 записями, у совпавшей песни 2 варианта; кнопка «Найти аудио» заполняет поисковый запрос.
- Снимок: docs/qa/catalog/home.png (тестовые данные).

## Ещё не завершено
- Живой поиск SoundCloud: прямое соединение с soundcloud.com завершилось fetch failed/таймаутом. API-парсер проверен фикстурами, воспроизведение живого результата не подтверждено.
- Полноценные аккаунты SoundCloud, пользовательские лайки/плейлисты и OAuth: пока отсутствуют. Официальный доступ требует регистрации приложения; публичный адаптер этого не заменяет.
- Яндекс: OAuth-клиент отклонён, веб-вход и импорт коллекции не реализованы.
- Spotify: код импорта есть, живой вход и разрешения приложения нуждаются в проверке.
- Кэш обложек хранит URL, не обеспечивает офлайн-доступ к изображениям. Источники могут менять доступность.
- Единый каталог является представлением поверх прежних записей; избранное/массовые действия пока работают через исходные ID, постоянный выбор приоритетного источника не реализован.
- Рекомендации пока основаны на исполнителях/любимом/истории; поиск новых аудио выполняется по запросу пользователя, автоматического фонового поиска всего каталога нет.

## Альбомы и обновление медиатеки — 2026-09-10
- Главная: отдельные вкладки альбомов и плейлистов, карточки открывают коллекцию.
- Слева: раскрываемые альбомы и плейлисты перед аккаунтами сервисов.
- Альбомы группируются по исполнителю и названию; пустые названия и заглушки сервисов исключаются.
- Включённое автообновление работает при старте, каждые две минуты в видимом окне и при возврате фокуса (не чаще раза в минуту). На главной есть ручное обновление всех аккаунтов и ошибки импорта.
- Новые импортированные треки помещаются первыми. Существующие ID, скрытия и пользовательские данные сохраняются; недостающее название альбома дополняется.
- Проверено: 434 теста, TypeScript, production build, изолированный Electron UI (две одноимённые карточки разных исполнителей; переход открывает один соответствующий трек). Скриншот: docs/qa/albums/home.png.
- Получение конкретного нового трека из живого аккаунта VK в этой проверке не подтверждено.
