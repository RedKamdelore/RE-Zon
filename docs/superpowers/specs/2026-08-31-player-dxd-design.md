# Player_DXD — дизайн-документ

Дата: 2026-08-31
Статус: утверждён

## Цель

Десктопный аудиоплеер для Windows (полноценный `.exe`), визуально повторяющий
десктопную версию Spotify. Источник музыки — сменный адаптер; в v1 это локальные
файлы + демо-контент, в следующем этапе — музыка со страницы ВКонтакте.

## Технологии

- **Electron + electron-builder (NSIS)** — упаковка в `.exe`-установщик
- **React 18 + TypeScript + Vite (electron-vite)** — UI
- **zustand** — состояние приложения
- **Web Audio API** — воспроизведение + 10-полосный эквалайзер (`BiquadFilter`)
- **music-metadata** (npm) — чтение тегов и обложек локальных файлов
- Хранение библиотеки и плейлистов — JSON-файл в `%APPDATA%/Player_DXD`
- **vitest** — юнит-тесты логики

## Архитектура

Три процесса Electron:

- **Main (Node.js)** — окно, системный трей, сканирование папок, чтение
  метаданных, persistence (JSON), IPC-хендлеры.
- **Preload** — типизированный мост через `contextBridge` (`window.api`).
- **Renderer (React)** — весь интерфейс и движок воспроизведения.

### Абстракция источника музыки

```ts
interface MusicSource {
  readonly id: string;
  getTracks(): Promise<Track[]>;
  resolveStreamUrl(trackId: string): Promise<string>;
}
```

Реализации:
1. `LocalFolderSource` — сканирование выбранных папок (mp3/flac/ogg/wav/m4a),
   теги, обложки.
2. `DemoSource` — встроенный демо-контент, если локальной музыки нет.
3. `VkSource` — следующий этап (музыка со страницы ВК), подключается без
   изменения остального кода.

## Интерфейс (в стиле Spotify desktop)

- **Левая панель**: навигация (Главная, Поиск), «Моя медиатека», плейлисты.
- **Центр**: Главная с плитками; экран плейлиста с таблицей треков (обложка,
  название, исполнитель, альбом, длительность); экран поиска.
- **Нижняя панель плеера**: обложка + название, shuffle/prev/play/next/repeat,
  seek-бар, громкость, кнопки очереди и мини-плеера.
- **Правая панель** (выдвижная): очередь / текст песни.
- Тёмная тема, акцент `#1DB954`.

## Функциональность v1

- Воспроизведение: shuffle, repeat (off/all/one), очередь (добавить/удалить/
  перетащить)
- Плейлисты: создание, переименование, обложка, добавление/удаление треков
- Поиск по библиотеке (трек / исполнитель / альбом)
- Эквалайзер: 10 полос, пресеты
- Тексты песен: из тегов + встроенный редактор
- Мини-плеер (компактное always-on-top окно)
- Системный трей (play/pause/next)

## Обработка ошибок

- Битые/нечитаемые аудиофайлы пропускаются, записываются в лог.
- Трек без обложки — плейсхолдер.
- Недоступный источник музыки — понятное сообщение в UI, приложение не падает.

## Тестирование

- vitest: очередь, shuffle/repeat-логика, плейлисты, поиск, парсинг источников.
- UI-логика — в чистых хуках/сторах, тестируется без Electron.

## Этапы

1. Скаффолд (electron-vite + React + TS), конфиги
2. Main-процесс: окно, трей, IPC
3. `MusicSource` + LocalFolderSource + DemoSource
4. Движок плеера (Web Audio + эквалайзер, zustand-стор)
5. Каркас UI: layout, тёмная тема, боковая панель
6. Список треков, Главная, Поиск
7. Плейлисты (CRUD + persist)
8. Очередь + правая панель + тексты песен
9. Мини-плеер и трей
10. electron-builder → `.exe`, прогон тестов

## Вне scope v1

- Интеграция с ВКонтакте (отдельный следующий этап — адаптер `VkSource`)
- Стриминг из внешних сервисов, кроме ВК
